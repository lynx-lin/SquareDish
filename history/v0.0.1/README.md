# 幸存者 · 三大关试玩

一个零依赖的 HTML5 Canvas 小游戏原型：主菜单 + 第一/第二/第三大关各 10 分钟试玩。

## 运行

直接双击 `index.html` 即可（不需要安装、构建或启动服务器）。

如果浏览器对本地脚本有限制，也可以在当前目录运行任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 操作

默认按键如下；主菜单进入“设置”后可以把上/下/左/右、奔跑、暂停、武器 1/2/3 主动全部改成别的键，设置会随存档保存。

| 默认按键 | 功能 |
|---|---|
| `W` / `A` / `S` / `D` | 移动 |
| `Shift` | 按住奔跑，消耗体力 |
| `1` / `2` / `3` | 武器主动键 |
| `Esc` | 暂停 / 继续 |
| `Enter` / `Space`（主菜单） | 开始游戏 |

主动技能按熟练度解锁（例如奥术球 2 级、毒弓 1 级、冰刺枪 2 级、粘性手雷 2 级）；兔子、弹簧陷阱等 0 级即可使用。测试版可以在武器选择界面把每件武器设为 0/1/2/3 级。

## 随机选择

- 武器选择界面新增“随机 3 件”：从 36 种武器中随机抽 3 件不重复武器，并分别为每件随机 0/1/2/3 级熟练度。
- 圣物选择界面新增“随机 3 件”：从 33 种圣物中随机抽 3 件不重复圣物，并自动避开冰晶体 + 墨鱼丸的互斥组合。
- 两个选择界面打开时也可以按 `R` 随机。随机结果仍可继续手动调整后再确认。

## 设置

主菜单的“设置”面板包含：

- **按键**：点击某个动作的按键按钮后按下新键；Esc 取消，重复按键会被拒绝，并提供“恢复默认按键”。
- **背景**：无背景（深色网格）、沙漠风（浅黄沙地 + 深色颗粒）、工业风（灰色网格 + 网格交点螺丝）、草原（浅绿草地 + 静态草）。
- **亮度**：60%–140%，实际叠加在游戏画面上。
- **音量**：0%–100%，会写入设置和存档；当前版本还没有音频资源，因此暂时不产生声音。
- **存档槽**：3 个槽位，可在设置里切换；当前槽会高亮显示等级、局数和通关数。

## 游戏记录

主菜单和设置里都可以打开“游戏记录”。每局结算会自动记录：

- 关卡、难度、结算时间和是否通关；
- 存活时间、击杀数、总伤害；
- 三件出战武器及其熟练度、各自造成的伤害。

每个存档槽独立保存最近 50 局记录。

## 图鉴

主菜单点击“图鉴”打开，分为武器、圣物、敌方三个标签页，数据直接读取当前游戏数据：

- **武器**：名称、ID、分类/机制标签、可造成伤害类型、粗略描述，以及结构化的被动效果、自动攻击、主动释放（无主动则省略）和熟练 1/2/3 级升级效果；设计文档中 `[]` 内的额外信息不会显示。
- **圣物**：名称、ID、获取方式、额外生命值、自然恢复和特殊机制。
- **敌方**：名称、ID、普通/精英/BOSS 标记、用当前绘制函数生成的游戏图像预览、普通/困难/极难三档生命值/速度/接触伤害，以及机制说明。
- 敌方图鉴包含分裂小史莱姆和蠕虫类单位，共 31 个条目。

## 存档

按《全局规则.txt》第九点实现三槽自动存档：

- 自动保存时机：关卡结算、返回主菜单、修改设置后。
- 当前保存：人物等级/经验、社区货币、按关卡+难度记录的通关状态、设置、背包数组、全部已解锁武器与圣物、武器熟练度数值+等级、当前武器/圣物选择、关卡/难度和游戏记录。
- 不保存：当前关卡内的生命、位置、冷却、临时 buff/debuff 等临时状态。
- 测试版还没有人物升级、货币消费、战利品背包和局外熟练度系统，因此对应字段会以默认值/空数组保存，结构已经预留。

## 关卡选择

主菜单“关卡”区可以选择 **第一/第二/第三大关**，和普通/困难/极难难度并列；选好后点击“开始游戏”。三关都使用 50×50 米地图、10 分钟时间轴、相同的玩家/武器/圣物系统，区别是敌人、精英和 BOSS。也可以直接用地址参数指定：

```
index.html?level=3
index.html?level=3&difficulty=hard
```

## 测试关卡

主菜单“测试关卡”按钮会直接进入专用测试关卡，不经过关卡和难度选择：

- 玩家自然生命恢复 **+100/s**，方便持续测试武器。
- 只刷新第一关精英 **紫藤蔓**，固定使用困难难度属性：660HP / 5接触伤害 / 0.7 移速。
- 刷新间隔固定为 **1 秒/只**，没有普通敌人、BOSS 或额外精英。
- HUD 会显示实时有效移速，包括当前行走/奔跑、圣物和减速效果。
- 测试关卡不写入正式游戏记录，也不会改变关卡/难度选择；暂停菜单可以返回主菜单。

## 武器选择

主菜单“武器”区点击“选择 3 件”，在 36 种武器中选满 3 件后确认；也可以点“随机 3 件”或按 `R` 一次随机武器和熟练度。每张武器卡下方可以单独设置 0/1/2/3 级熟练度，HUD 的 `1/2/3` 会按当前选择的顺序对应三件武器。

- **奥术球**：每 0.2s 向随机方向发射追踪法球，10 点能量真实伤害。
- **毒弓**：每 0.7s 射最近敌人，15 物理尖刺 + 毒。
- **兔子饲养手册**：兔子原地待机，每 0.5s 冲刺 4m；两只兔子时一只冲向离玩家最近的敌人，另一只冲向当前血量最高的敌人。
- **弹簧陷阱工具箱**：移速 +20%；静止 1s 布置弹簧陷阱，踩中的敌人被弹飞并在落地时受伤。
- **食人鱼**：锁定 6m 内血量最高的敌人，持续减速并每 0.5s 撕咬，咬痕会提高伤害。
- **永生剑**：近身每 0.4s 自动斩击；无敌人时开始蓄力，熟练 2/3 级蓄力圈为 3 秒。
- **音乐炸弹工具箱**：每 5.6s 获得一颗音乐炸弹（上限 2），放置后吸引敌人，被摧毁时范围爆炸。

### 进阶武器

- **热能枪**：持续积攒热量，主动消耗全部热量发射射线；满热量会自伤，熟练 1 后改为加速。
- **尖刺地雷工具箱**：静止布置地雷，踩中后造成剩余尖刺值真伤并爆炸；熟练 2 改为备用雷 + 主动放置。
- **重力法书**：自动生成重力场，立即伤害并减速；熟练 2 会吸引非精英敌人，精英免疫吸引；熟练 1 解锁快速吟唱。
- **经验卷轴**：生成环绕经验球攻击近身敌人；主动切换成长模式，其他武器伤害提高 25%，自身移速 -20%。
- **避雷针工具箱**：静止建造避雷针，自动落雷；熟练 1 增加数量，熟练 3 增加范围和玩家加速。
- **寒冰爆裂球**：六方向冰球爆炸减速；熟练 2 解锁五连投掷，熟练 3 自动爆炸和更大范围。
- **空手接白刃**：白刃格挡一次攻击并反伤；主动消耗白刃发射飞刀；熟练 3 可存 2 把白刃。
- **火焰车**：火焰车冲向前方并造成碰撞/持续伤害；熟练 1 可切换绕圈模式。
- **暗影长矛**：穿透幻影矛；主动短距离无敌冲刺，熟练 3 给目标挂易伤。
- **香蕉回旋镖**：追踪回旋镖以最大 45°/s 的转向速度追踪，击中恢复体力；主动恢复 20 体力。

### 老手武器

- **果物法杖**：生长模式积攒营养，结果模式散落并引爆果实。
- **专心拳套**：近身单体持续输出，目标越单一伤害越高。
- **冰语**：静止吟唱后释放环形冰波，造成伤害、减速和易伤。
- **邪恶缠绕**：诅咒敌人，使其按当前移速持续受到真实伤害。
- **冰寒对峙**：吟唱后持续攻击范围内最高血量敌人，并提高移速。
- **多彩糖果**：向周围抛糖，糖果飞行 0.2 秒后落地；飞行碰撞或落地后踩中都会造成随机属性伤害。
- **殒命刀**：积攒殒命值，主动消耗全部对最近敌人造成能量伤害。
- **森林靴**：移速 +10%，移动时留下伤害并减速敌人的尖刺丛。
- **鲜血飞刀**：消耗生命发射环形飞刀，击杀回血；熟练 2 解锁强化。
- **作弊代码**：锁定敌人数秒后秒杀非精英或重创精英；受伤后短暂无敌。

### 社区武器

- **毒胞召唤书**：静止吟唱召唤毒胞，毒胞追敌自爆并传播胞毒；被胞毒感染的敌人死亡后会变成新的毒胞。
- **冰刺枪**：发射冰球减速敌人并留下冰刺地，敌人在冰刺地内每移动 0.1m 受到 1 点伤害；熟练 2 可切换随机/最远/最近/最高血量索敌。
- **致命骰子**：每 2 秒投一次骰子，可能回血、重击、获得一次性骰盾、发射环形弹幕、全屏真伤或连锁重投；熟练 2 起不会掷出当前无效的 1/2/3 点。
- **发射器工具箱**：静止 2.5 秒建造发射器，自动向 6m 内敌人发射穿透箭；发射器有生命值，可被敌人攻击。
- **亡灵之书**：击杀积攒魂魄并提高移速；吟唱消耗魂魄召唤跟随玩家的亡灵护卫，护卫会近战，并把玩家受到的远程伤害转移给自己；熟练 3 可远程射箭。
- **榴莲盒**：投掷榴莲酥叠加气味并放大敌人；2 层起释放榴毒气场，持续造成毒伤，熟练 2 后附加 12% 易伤。
- **粘性手雷**：向 5m 内随机敌人投掷粘性手雷，1 秒后范围爆炸；熟练 2 可让 5m 内所有敌人同时粘雷。
- **彩色气球**：按住主动蓄气 2–3 秒后松开，放出追踪气球；按满 3 秒会在原地爆炸并自伤 5。
- **气球吹气装置**：单独携带时每 0.4 秒喷气；与彩色气球同带时每 2 秒自动吹气球，主动升空 3 秒后大爆炸。两件武器同带时，彩色气球的熟练度加成同样生效。

## 圣物选择

主菜单“圣物”区点击“选择圣物”，从 33 种圣物中最多选择 3 件；可以不选，也可以少于 3 件；也可以点“随机 3 件”或按 `R`。当前按要求，33 种圣物在所有关卡通用。冰晶体与墨鱼丸不能同时携带。选择会随当前存档槽保存。

- **史莱姆核心**：+4HP；致命伤害时半血复活一次。
- **冰晶体**：+4HP；物理伤害转为冰系。
- **墨鱼丸**：+4HP；物理伤害转为毒系。
- **行者围巾**：+4HP；奔跑速度 +0.4，体力恢复 +2/s。
- **狗头金**：+4HP；接触伤害单次最多 6。
- **羊毛帽**：+4HP；接触伤害 -1。
- **藤蔓护盾**：+8HP；满血时非真实伤害 -50%。
- **金蜥蜴牙**：+4HP；对生命值低于 15 的敌人伤害 ×1.25。
- **月亮岩**：+8HP；自然恢复 +0.2/s。
- **咒术之铠**：+10HP；完全抵御一次 debuff，冷却 15 秒。

## 调试模式

在地址后加 `?debug=1`：

```
index.html?debug=1
```

会显示关卡、FPS、难度、敌人数、时间和玩家坐标。

调试键：

- `T`：时间 +30 秒（用于快速测试 10 分钟时间轴和 BOSS）。
- `H`：切换无敌。

## 已知简化

- 冰球/毒弹的弹速与寿命文档未写，本版定为 4 m/s、3 秒、半径 0.1 米。
- 刷怪间隔从开局的约 1.28 秒逐渐降到 1.2 秒；相比旧版 1.8 秒开局，早期刷怪效率提高约 40%，最终速率保持 1.2 秒一波。每波数量和同屏上限集中在 `game.js` 的 `LEVEL` 数据里。
- 狗头金的“接触伤害单次最多 6”已实现；第二关生死门卫的接触伤害最高为 7，因此该圣物会实际发挥作用。
- 难度和关卡选择会随当前存档槽保存；仍可用 `?difficulty=` / `?level=` 临时指定。
- 设置里的音量目前只保存数值，没有音频资源；亮度会实际改变游戏画面，背景只作用于关卡画面，不改变主菜单面板。
- 存档使用浏览器 `localStorage`；清理浏览器站点数据会清空存档。当前没有删除/重命名存档槽的入口，切换槽位时会先自动保存当前槽。
- 测试关卡是无限模式，没有 BOSS 和 10 分钟结算；它不会写入正式游戏记录或通关状态，退出方式为暂停菜单返回主菜单或死亡后返回。
- 测试关卡的“移速”显示的是当前有效移速（包含奔跑、圣物、减速等修正），站立不动时显示未奔跑的行走速度。
- 人物等级/经验、社区货币、背包数组、武器解锁列表和圣物解锁列表已按存档结构写入，但测试版还没有对应的升级、商城、掉落和局外熟练度玩法，因此大多保持默认值。
- 极难冻尸的“免疫减速”会让食人鱼和永生剑的减速无效；极难毒尸的“免疫持续伤害”在当前内容里主要体现为毒弓不能上毒。
- 熟练度只在测试版通过选择 0/1/2/3 级设置，没有做局内成长。
- 兔子按“原地待机、冷却好才冲刺”实现，不会跟随玩家，也不会每次回到玩家身边。
- 食人鱼和永生剑的减速对同一敌人取最强效果并刷新持续时间，没有做多来源乘算。
- 音乐炸弹基础上限 2 颗，熟练 3 级提高到 3 颗；场上炸弹没有数量上限。
- 弹簧陷阱基础 14 伤/3 触发/4 个，熟练 1–3 会提高触发、上限、伤害、击退和减速；精英分支已接入。
- 测试版熟练度选择会写入当前存档槽；由于没有局外成长，它仍只是赛前 0/1/2/3 档位。
- 测试版圣物选择也会写入当前存档槽；胜利宝石和余孽果未做“首次通关”限制，直接可选。
- 冰晶体/墨鱼丸会转化物理直伤和物理真实伤害；冻尸仍免疫冰系，毒尸仍免疫毒系。
- 咒术之铠当前只拦截会作用于玩家的减速和中毒；没有实现眩晕、黑暗、束缚等其他 debuff。
- 史莱姆核心的复活会清除减速和中毒，并给 1 秒无敌，避免复活瞬间再次被秒。
- 经验卷轴的成长模式用“其他武器伤害 ×1.25”代替局内熟练度加成；3 级溢出转护盾尚未实现。
