# 方形皿·测试版

一个零依赖的 HTML5 Canvas 小游戏原型：带 AI 实战演示背景的主菜单 + 第一/第二/第三大关各 10 分钟试玩。

## 运行

直接双击 `index.html` 即可（不需要安装、构建或启动服务器）。

如果浏览器对本地脚本有限制，也可以在当前目录运行任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 操作

默认按键如下；主菜单进入“设置”后可以把上/下/左/右、奔跑、暂停、武器 1/2/3 主动全部改成别的键，设置会随存档保存。

| 默认按键 | 功能 |
|---|---|
| `W` / `A` / `S` / `D` | 移动 |
| `Shift` | 按住奔跑，消耗体力 |
| `1` / `2` / `3` | 武器主动键 |
| `Esc` | 暂停 / 继续 |
| `Enter` / `Space`（主菜单） | 开始游戏 |

主动技能按熟练度解锁（例如奥术球 2 级、毒弓 1 级、冰刺枪 2 级、粘性手雷 2 级）；兔子、弹簧陷阱等 0 级即可使用。全局武器熟练度达到 300/700/1200 后，武器选择界面才会开放对应的 1/2/3 级；也可以继续选择更低等级。

## 随机选择

- 武器选择界面新增“随机 3 件”：从当前已解锁武器中随机抽 3 件不重复武器，并分别为每件随机当前已解锁的熟练等级。
- 圣物选择界面新增“随机 3 件”：从当前已解锁圣物中随机抽 3 件不重复圣物，并自动避开冰晶体 + 墨鱼丸的互斥组合。
- 两个选择界面打开时也可以按 `R` 随机。随机结果仍可继续手动调整后再确认。

## 背包、战利品与社区商店

- 击杀敌人有概率掉落战利品，直接进入战利品背包，无需拾取。
- 掉落率：困难 ×1.5、极难 ×2，最高 100%；复活的敌人不会掉落。
- 掉落时在敌人死亡位置显示“物品名 +1”，持续 1 秒。
- 主菜单“背包 / 商店”中：
  - 右侧背包按物品堆叠显示；普通战利品可出售 1 个或全部，获得社区货币，“全知体验”可单独使用或全部使用。
  - 左侧社区商店新增“社区武器 / 社区道具”分类标签；社区武器统一价格 160 社区货币，社区道具“全知体验”和“瓶装魂魄”均售价 50 社区货币。社区武器初始未解锁。
  - “全知体验”购买后进入战利品背包，使用后使所有已解锁武器的熟练度 +50，单项最高不超过 1200；可以一次使用 1 个或全部使用。
  - “瓶装魂魄”购买后进入战利品背包，使用后增加 100 人物经验；可以一次使用 1 个或全部使用，达到人物等级上限后不会继续消耗。
  - 背包右上角新增“制造台”按钮。制造台左侧列出 10 个可制造配方，右侧按“蓝图 / 合成材料”分组显示现有背包；配方会逐一显示材料拥有量/需求量。
  - “社区道具”页新增 10 张制造蓝图：血肉柱、送葬人、幻造兽、腐化蘑菇、振荡保险箱、飞水手里剑、纱盾、邪恶蔓岩、枯萎原核、丰饶原核。每张统一售价 50 社区货币，每种限购 1 张，买入后进入背包且无法出售。
  - 制造会消耗对应蓝图和全部材料；制造成功后永久解锁该熔炼武器或制造圣物，并可在武器/圣物选择中携带。已制造的蓝图在商店中显示“已制造”，不能重复购买。
  - 制造材料来自战利品：史莱姆粘液、冻肉、霉肉、幻纱、锈盾、紫棘、毒液、漂浮岩、咒符、枯萎核心、丰饶核心、彼岸核心、灵魂棺木、幻造细胞、幻造胞体、食用菌、地下核心、腐化甲壳、振荡灵、硬铁、遗迹银币、银币、生命水、陀螺仪。
  - 熔炼武器与社区武器一样不进入人物升级解锁池；熔炼武器在武器选择中标记为“制造台合成后解锁”。
- 香蕉回旋镖熟练 2 时，香蕉击杀敌人的战利品掉落概率 ×1.2，最高 100%。
- 战利品文本来自 [战利品设计.txt](plan/战利品设计.txt)，当前没有图片，仅用文字展示。

## 设置

主菜单的“设置”面板包含：

- **按键**：点击某个动作的按键按钮后按下新键；Esc 取消，重复按键会被拒绝，并提供“恢复默认按键”。
- **背景**：虚空（深色棋盘）、沙漠（浅黄沙地 ）、工业（灰色网格）、草原（浅绿草地 ）；主菜单背景也会使用当前设置，并实时演示 AI 使用 3 件随机武器的战斗。
- **亮度**：60%–140%，实际叠加在游戏画面上。
- **音量**：0%–100%，会写入设置和存档；当前版本还没有音频资源，因此暂时不产生声音。
- **存档槽**：3 个槽位，可在设置里切换；当前槽会高亮显示等级、局数和通关数。

## 游戏记录

主菜单和设置里都可以打开“游戏记录”。每局结算会自动记录：

- 关卡、难度、结算时间和是否通关；
- 存活时间、击杀数、总伤害；
- 三件出战武器及其等级、各自造成的伤害。

每个存档槽独立保存最近 50 局记录。

## 图鉴

主菜单或游戏内暂停菜单点击“图鉴”打开，分为武器、圣物、敌方三个标签页，数据直接读取当前游戏数据：

- **武器**：名称、ID、分类/机制标签、可造成伤害类型、粗略描述，以及结构化的被动效果、自动攻击、主动释放（无主动则省略）和熟练 1/2/3 级升级效果；设计文档中 `[]` 内的额外信息不会显示。
- **圣物**：名称、ID、获取方式、额外生命值、自然恢复和特殊机制。
- **敌方**：名称、ID、普通/精英/BOSS 标记、用当前绘制函数生成的游戏图像预览、普通/困难/极难三档生命值/速度/接触伤害，以及机制说明。
- 敌方图鉴包含分裂小史莱姆和蠕虫类单位，共 31 个条目。

## 存档

按《全局规则.txt》第九点实现三槽自动存档：

- 自动保存时机：关卡结算、返回主菜单、修改设置后。
- 当前保存：人物等级/经验/升级额度、开局选择的 3 件新手武器、社区货币、按关卡+难度记录的通关状态、设置、背包数组、全部已解锁武器与圣物、武器熟练度数值+等级、当前武器/圣物选择、关卡/难度和游戏记录。
- 不保存：当前关卡内的生命、位置、冷却、临时 buff/debuff 等临时状态。
- 设置中的每个存档槽新增“删除”按钮，删除前会弹出确认框，确认后清空该槽并重置为默认存档；删除当前槽后需要重新选择 3 件开局武器。
- 社区武器不能通过升级额度解锁，只能通过社区商店以 160 社区货币购买；已购买状态会写入存档。“全知体验”和“瓶装魂魄”可重复购买并堆叠在背包中。
- 制造蓝图、合成材料、已制造的熔炼武器和制造圣物都会写入当前存档槽；蓝图被消耗后，对应物品的永久解锁状态仍保留。

## 关卡选择

主菜单“关卡”区可以选择 **第一/第二/第三大关**，和普通/困难/极难难度并列；选好后点击“开始游戏”。三关都使用 50×50 米地图、10 分钟时间轴、相同的玩家/武器/圣物系统，区别是敌人、精英和 BOSS。也可以直接用地址参数指定：

```
index.html?level=3
index.html?level=3&difficulty=hard
```

## 新存档开局选择

新建存档时，所有武器初始未解锁，必须先通过弹出的开局选择，从 **7 种新手武器**里正好选择 **3 件**作为本存档的开局武器；未选择前不能开始游戏，也不能打开武器选择。

- 人物 **2–5 级**获得的升级额度只能解锁尚未解锁的 **新手**武器。
- 人物 **6–15 级**获得的升级额度只能解锁尚未解锁的 **进阶**武器。
- 人物 **16–25 级**获得的升级额度只能解锁尚未解锁的 **老手**武器。
- 升级额度按品质分别保留，后续升级不会让未使用的新手/进阶额度失效。
- 社区武器不能通过升级额度解锁，只能使用社区货币购买。
- 旧存档保留原有解锁状态和当前出战武器，不会被新开局选择覆盖。

## 武器选择

主菜单“武器”区点击“选择 3 件”，从当前已解锁武器中选满 3 件后确认；也可以点“随机 3 件”或按 `R` 一次随机武器和当前可用熟练等级。每张武器卡下方只显示已解锁的熟练等级：0 级始终可用，全局熟练度达到 300/700/1200 后分别解锁 1/2/3 级；即使已经解锁高阶，也可以继续选择低阶。HUD 的 `1/2/3` 会按当前选择的顺序对应三件武器。

- **奥术球**：每 0.2s 向随机方向发射追踪法球，10 点能量真实伤害。
- **毒弓**：每 0.7s 射最近敌人，15 物理尖刺 + 毒。
- **兔子饲养手册**：兔子原地待机，每 0.5s 冲刺 4m；两只兔子时一只冲向离玩家最近的敌人，另一只冲向当前血量最高的敌人。
- **弹簧陷阱工具箱**：移速 +20%；静止 1s 布置弹簧陷阱，踩中的敌人被弹飞并在落地时受伤。
- **食人鱼**：锁定 6m 内血量最高的敌人，持续减速并每 0.5s 撕咬，咬痕会提高伤害。
- **永生剑**：近身每 0.4s 自动斩击；无敌人时开始蓄力，熟练 2/3 级蓄力圈为 3 秒。
- **音乐炸弹工具箱**：每 5.6s 获得一颗音乐炸弹（上限 2），放置后吸引敌人，被摧毁时范围爆炸。

### 进阶武器

- **热能枪**：持续积攒热量，主动消耗全部热量发射射线；满热量会自伤，熟练 1 后改为加速。
- **尖刺地雷工具箱**：静止布置地雷，踩中后造成剩余尖刺值真伤并爆炸；熟练 2 改为备用雷 + 主动放置。熟练 2 时只要保持静止就会积攒备用地雷进度，1.6 秒获得 1 颗；移动只会暂停进度，不会清空已积攒的时间。
- **重力法书**：自动生成重力场，立即伤害并减速；熟练 2 会吸引非精英敌人，精英免疫吸引；熟练 1 解锁高速模式，高速模式会锁定 7.2m 内随机一名敌人。
- **经验卷轴**：生成环绕经验球攻击近身敌人；主动切换成长模式，其他武器熟练度获取 ×2，自身移速 -20%；熟练 3 会把溢出的熟练度按 10% 转化为无持续时间护盾，上限为最大生命的 25%。
- **避雷针工具箱**：静止建造有 60HP 的避雷针，自动落雷；熟练 1 增加数量，熟练 3 增加范围和玩家加速。敌人可以攻击并摧毁避雷针。
- **寒冰爆裂球**：六方向冰球爆炸减速；熟练 2 解锁五连投掷，熟练 3 自动爆炸和更大范围。
- **空手接白刃**：白刃格挡一次攻击并反伤；主动消耗白刃发射飞刀；熟练 3 可存 2 把白刃。
- **火焰车**：火焰车冲向前方并造成碰撞/持续伤害；熟练 1 可切换绕圈模式。
- **暗影长矛**：穿透幻影矛；主动短距离无敌冲刺，熟练 3 给目标挂易伤。
- **香蕉回旋镖**：追踪回旋镖以最大 45°/s 的转向速度追踪，击中恢复体力；主动恢复 30 体力。视觉为 120° 夹角并绕三角形重心旋转。

### 老手武器

- **果物法杖**：生长模式积攒营养，结果模式散落并引爆果实。
- **专心拳套**：近身单体持续输出，目标越单一伤害越高。
- **冰语**：静止吟唱后释放环形冰波，造成伤害、减速和易伤。

## 熟练度与人物等级

### 武器熟练度

- 每件武器拥有独立的**全局熟练度**，按当前存档槽累计，跨关卡、难度和武器配置共享；不再有单独的局内熟练度进度。
- 击杀普通敌人：所有携带武器 **+1**；精英 **+10**；BOSS **+40**。BOSS 同时属于精英，但只结算 BOSS 的 40。
- 每连续生存 **10 秒**：所有携带武器 **+1**，与击杀计时互不影响。
- 每张地图生成 **2 个遗迹**，位于中心 25×25 区域之外、45×45 区域之内。在遗迹内连续停留 **10 秒**，所有携带武器 **+20** 并获得 **1 个遗迹银币**；离开会立即清空该遗迹的进度，每个遗迹只能触发一次。
- 熟练度上限 **1200**；超过上限的部分作为“溢出”，可用于经验卷轴的 3 级效果，不增加全局数值。
- 全局熟练度达到 **300/700/1200** 时分别解锁该武器的熟练 1/2/3 级；武器选择界面仍可选择任意已解锁的低阶，例如 300 熟练度时可以继续选择 0 级。对局中提高的熟练度会立即记入全局数值，但不会自动改变本局已选的武器等级。
- 全局熟练度在获得时立即累加，并在关卡结算、死亡、重新开始或返回主菜单时写入当前存档槽。

### 人物等级

- 普通敌人击杀经验为 **1**，精英 **10**，BOSS **40**；分裂或复活产生的敌方单位击杀经验为 **0**。
- 普通敌人的经验从 **3:00** 开始每分钟 -10%，最低为原值的 **20%**；精英和 BOSS 不衰减。
- 1→2 级需要 **200** 经验，之后每级需求比上一级多 **40**，最高 **25 级**。
- 升级会获得 1 个对应品质的升级额度：2–5 级为新手额度、6–15 级为进阶额度、16–25 级为老手额度；额度会一直保留，不会因为人物继续升级而失效。升级只提升人物等级并解锁武器，不会改变当前关卡携带的 3 件武器。
- 游戏内升级只显示提示，不弹出选择界面；主菜单中人物等级右侧会在有可用升级额度时出现“选择新武器”按钮。点击后，新手额度只能解锁新手武器，进阶额度只能解锁进阶武器，老手额度只能解锁老手武器；社区武器和熔炼武器不进入升级池。
- 人物等级、经验、升级额度和已解锁武器都会写入当前存档槽。

## 已知简化

- 冰球/毒弹的弹速与寿命文档未写，本版定为 4 m/s、3 秒、半径 0.1 米。
- 刷怪间隔从开局的约 1.28 秒逐渐降到 1.2 秒；相比旧版 1.8 秒开局，早期刷怪效率提高约 40%，最终速率保持 1.2 秒一波。每波数量集中在 `game.js` 的 `LEVEL` 数据里；同屏敌人上限为普通 60、困难 80、极难 100（`DIFFICULTY_SPAWN_CAPS`）。
- 狗头金的单次受伤上限为 5，对接触、射弹、真实伤害等所有伤害实例生效；第二关生死门卫的接触伤害最高为 7，因此该圣物会实际发挥作用。
- 难度和关卡选择会随当前存档槽保存；仍可用 `?difficulty=` / `?level=` 临时指定。
- 设置里的音量目前只保存数值，没有音频资源；亮度会实际改变游戏画面。背景和亮度同时作用于关卡画面和主菜单的 AI 演示。
